# Bootloader sources and notices

The unmodified `optiboot/` and `atmega/` sources and ATmega328P bootloader HEX files
are copied from **Arduino AVR Boards / ArduinoCore-avr 1.8.6**:

https://github.com/arduino/ArduinoCore-avr/tree/1.8.6/bootloaders

- `optiboot/`: Arduino-maintained Optiboot, used by the `nano` profile.
- `atmega/`: ATmegaBOOT_168, used by the `nano-old` profile.
- The respective source headers retain their author/copyright notices and
  GNU GPL version 2 or later terms. See `COPYING-GPL-2.0.txt`.
- Optiboot's `boot.h` retains its avr-libc BSD notice in that source file.

The combined application/bootloader HEX files in `../releases/` include the
selected bootloader. They are generated by Arduino CLI with the pinned AVR core,
not by copying a bootloader into a running sketch. The original Makefiles are
provided with the sources; Arduino CLI also ships the prebuilt bootloader images.

Arduino core/Wire source and its original notices are available at:
https://github.com/arduino/ArduinoCore-avr/tree/1.8.6
The linked Arduino core uses LGPL 2.1 or later; see `COPYING-LGPL-2.1.txt` and
the original per-file notices. Rebuild the application using `../manage.py` and
the documented Arduino core version. Sensor firmware is not included or replaced.
